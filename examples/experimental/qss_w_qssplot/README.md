# Atomics QSS with output for QSSPlot

## QSSPlot Visualizer
The QSSPlot visualizer is a tool that comes with RetQSS developed by Lucio Santi. For more information about RetQSS please check this reference:

* _Santi, L., Fernández, J., Kofman, E., & Castro, R. (2022). retQSS: A novel methodology for efficient modeling and simulation of particle systems in reticulated geometries. Computer Physics Communications, 270, 108157._

To use QSSPlot you have to clone the RetQSS repository:
```bash
git clone https://gitlab.com/lukius/retqss.git
```

You will find QSSPlot under the folder `src/plot/`. QSSPlot is based on a Python 2 script, so it is not necessary to install RetQSS to use it.

## Visualize the qssplot file produced by a QSS atomic model

In what follows we assume we are standing in the local folder, i.e. `examples/experimental/qss_w_qssplot/qssplot/`.

The output files generated by these atomic models can be found under the folder `output/plots/` with extension `qssplot`. In case there are multiple qssplot files, it is recommended to sort them by time (the lower the newer):
```bash
ls -ltr ../../output/plots/
```

To visualize a `qssplot` file generated with a QSS atomic model from **inside the docker container** you can provide an absolute path:
```bash
python plot.py /powerdevs/output/plots/<qssplot file>.qssplot x
```
or a relative path:
```bash
python plot.py ../../output/plots/<qssplot file>.qssplot x
```
