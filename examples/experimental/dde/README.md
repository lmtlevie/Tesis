# Parameter sweeping
This examples extends the cellular_networs_spikes example, by plotting the state evolution in the state-space and considering that initial conditions for the two integrators are model parameters. These parameters are then sweeped according to a sweeping file.

## Model building
First of all, since the model was developed using the GUI, it must be built to have the model executable as follows:

```bash
cd <powerdevs-folder>
bin/pdppt -m examples/experimental/dde/cellular_network_spikes_ss.pdm
cd build/
make clean && make
```

## Parameter sweeping
To run the parameter sweeping analysis we use the script `parameter_sweep.py`. Make sure that this file is set as executable (otherwise run `chmod +x parameter_sweep.py`). We need to indicate that the parameters to be sweeped (that is, the initial conditions of the integrators) are declared in the file `initial_conditions.sweep`, that the simulation will be run alonn 10s and that we will be using 2 threads to perform the analysis. All these boilds down to the following line:
```bash
./parameter_sweep.py --params_to_sweep initial_conditions.sweep --simulate_time 10 --processes 1
```

We will notice a folder named `results_simu_initial_conditions.sweep` with the results of the parameter sweeping analysis. In this folder, there will be subfolders for every analysis (identified by the date and time the analysis was performed) which contains the resulting files, namely: `initial_conditions.sweep` (the CSV with parameters values), `simu<number>.log` (debug file), `simu<number>.h5` (simulation log file), and a couple of plt and csv files generated by the gnuplot atomic model.

## House keeping
After running the simulation, kill all the gnuplot processes with the following line:
```bash
kill -9 $(pgrep gnuplot)
```
otherwise, there might be issues running the following analysis.
