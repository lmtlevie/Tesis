# PowerDEVS

Welcome to the PowerDEVS repository.

* `powerdevs_i386.deb`: Debian package for Ubuntu 10.04+ 32 bits.
* `powerdevs_amd64.deb`: Debian package for Ubuntu 10.04+ 64 bits.
* `powerdevs_install.exe`: Windows installer including gcc/Scilab/gnuplot for Windows Xp/7.

The project includes 2 main applications which are compiled separately:
- **PowerDEVS GUI**: the source code is located in `/src` and include different independent utilities (`pdme` is the main GUI).
   - To compile use the Makefile in the root directory
- **PowerDEVS simulation**: the source code is located in `/src`, `/atomics` and `/build`. 
   - `/src`: contains the source code for the DEVS core simulation engine. Users usually do not need to change these files.
   - `/atomics`: contains the source code for atomics models. Users usually use and add new files here.
   - `/build`: contains code autogenerated by the GUI including the model description (model.h) and build files (Makefile.include).
   - `/examples`: contains the model descriptions (either in `.py` for Py2PowerDEVS or in `.pdm` for the GUI), as well as auxiliary files (parameters, plotting, etc).
    
    - To produce a simulation executable it is better to use the GUI to generate the model description (top coupled model).
    - Alternative to the GUI, the Python binding (Py2PowerDEVS) can be used to define the model. Instead of the autogenerated `model.h`, the model can be described with Python. In this case the engine and atomic models are still compiled in C++ using `make py2pdevs``. 

## PowerDEVS installation

### Local installation

To install PowerDEVS locally, detailed installation instructions can be found [here](README-installation.md).

### Docker

In the `container/` directory you can find a ready to use docker image with all PowerDEVS dependencies installed.

Refer to [/container/README.md](container/README.md) for instructions on how to install, compile and execute. 



## Requirements
See `container/Dockerfile-\<XX\>.txt` for a full list of required packages:
- `g++ > 5.4`
- `qt > 4`
- `boost > 1.47`
- `python > 2.7`
- `gnumake > 4.1`
